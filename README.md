# 大肥鱼桌宠

Android 桌面宠物。装好之后，它会以悬浮窗的形式待在其他应用上面，不影响正常使用手机。支持 Android 10 及以上。

平时它会自己在屏幕上走动、发呆、打盹。点一下会弹一下，按住可以拖到任何位置，甩出去会飞一段再停下。双击打开面板，可以看 DeepSeek 余额、本机用量和天气；长按弹出菜单，里面能换动作、喂食、让它休息。

## 安装

从 [Releases](https://github.com/Miyukiji/fatfishpet-apk/releases) 下载 APK 安装。第一次打开时，系统会要求「显示在其他应用上层」权限，允许之后桌宠才会出现。

## 可选功能

桌宠本身不需要登录，也不需要电脑配合。下面这些按需开启：

- 余额：在 App 里填 DeepSeek API Key，或者登录 DeepSeek 平台账户。
- 本机用量和状态联动：电脑上需要运行 DSH（DeepSeek Harness），并安装 App 内导出的桥插件。
- 天气：需要联网，定位权限可以不给。
- 游戏或全屏时自动收起：需要开启无障碍服务；「先躲起来」还需要使用情况访问权限。

这些都不配置，桌宠也能正常使用。
